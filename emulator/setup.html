Set Up Your Tiny AI Screen

Connect the board to your WiFi network directly from this page — no software to install, no files to edit.

  1. Plug the board into this computer via USB-C
  2. Click Connect below and pick its serial port
  3. Enter your WiFi network name & password
  4. The board finds this companion app automatically — no further setup
Your browser doesn't support the Web Serial API needed for this. Please use Google Chrome or Microsoft Edge on a desktop computer.
This page needs to be loaded over http://localhost or HTTPS to access the serial port.
