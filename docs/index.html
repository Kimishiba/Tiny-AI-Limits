wifi Zero-Tool Provisioning

1-Click WebSerial Wi-Fi Setup

No need to install Arduino IDE or edit source code to set your Wi-Fi credentials. Connect your ESP32-C3 SuperMini over USB-C and provision your network credentials directly in Chrome / Edge.

1 Plug your ESP32-C3 SuperMini into USB-C.
2 Click the Connect to ESP32 button on the right.
3 Select your device port and submit Wi-Fi SSID & Password.
